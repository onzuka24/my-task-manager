# Glossary — my-task-manager

本ファイルの語彙は SPEC.md と `ARCHITECTURE-SPINE.md` の全体で厳密に使用される。**同義語の導入は禁止する。** 新たなドメイン語を導入する場合は、本ファイルの両方の表への追加を同時に行う。

## 語彙

- **タスク (Task)** — 一つの達成対象。1 個以上の**ステップ**を順序付きで内包する。
- **ステップ (Step)** — **タスク**内の作業単位。タスク内で No.1 から No.N まで通し番号を持つ。着手前に概ね定義され、進行中に詳細が追記されうる。タスクに対して 1..N。**完了**の状態を持つ。
- **完了 (Completion)** — **ステップ**に対してユーザーが明示的に宣言する状態。**現在地**の位置からは導出されない — 現在地が前のステップへ戻っても、後続のステップの完了は取り消されない。
- **現在地 (Current Position)** — 「どの**タスク**の第何**ステップ**にいるか」を指す唯一のポインタ。システム全体で同時に一つのみ存在する。**活性**と**非活性**の二状態を持ち、**休息**中は非活性となるが値は保持される。値を持たない状態は未着手時のみ。
- **次の一手 (Next Action)** — **現在地**が指している**ステップ**そのもの。既定の表示単位であり、オーバーレイが何も操作されていない状態で見せる唯一の項目。独立した実体ではなく表示上の呼称である。
- **中断メモ (Interruption Note)** — **現在地**を離れる際に記録される、再開に必要な最小限の文脈。ステップに対して 0..1。
- **本日計画 (Day Plan)** — その日に取り組む**タスク**の順序付き列。各タスクに想定の時間配分を持つ。一日に対して 0..1。開始時刻を持ち、各タスクの**移行期待時刻**は想定時間の累積で定まる。
- **ずれ (Drift)** — **本日計画**が想定する進行と、**現在地**の実際の進行との差分。
- **交差 (Crossing)** — **本日計画**が次の**タスク**への移行を要求している一方で、**現在地**が**ステップ**の途中にある状態。**ずれ**の特殊形であり、本ツールが検出対象とする中心的な状態。
- **切り替え (Switch)** — **現在地**をあるステップから別のステップへ移す操作。**中断メモ**の記録機会を伴う。
- **オーバーレイ (Overlay)** — グローバルホットキーにより最前面へ呼び出される UI。フォーカスを取得する通常ウィンドウとして実装される。**常駐プロセスの唯一の可視面ではない** — 常駐プロセスは Dock に現れない代わりに、メニューバー項目 (macOS の `NSStatusItem`) を常在する第二の可視面として持つ。メニューバー項目は明示的な終了への唯一の到達経路であり、ホットキーの現在状態を示す 1 行のみを持つ。バッジ・件数・進捗・一覧をそこに出してはならない (AD-15)。
- **常駐プロセス (Resident Process)** — 常時バックグラウンドで動作し、ホットキー受付・**ずれ**検出・**介入**の発火を担う実行主体。
- **介入 (Intervention)** — **常駐プロセス**がユーザーの呼び出しを待たずに発する能動的な通知。**交差**・**休息**・**待機**の契機を持つ (休息の契機は休息に入るよう促すものと、**復帰の介入**の二つ)。入力先を奪わない非活性パネルとして実装され、表示されるのは同時に一つだけである。
- **休息 (Rest)** — 作業から離れている状態。**現在地**は値を保持したまま非活性となる。**連続作業時間**の計数は停止する。
- **休息の長さ (Rest Length)** — **休息**に入ってから**復帰の介入**を発するまでの時間。「もう少し休む」が選ばれた後に出直すまでの時間でもある。既定 10 分。**休息**を時間で終わらせる長さではない。
- **復帰の介入 (Return Intervention)** — **休息**が**休息の長さ**を超えたときに発する**介入**。「休息を終える」「もう少し休む」の二択を示し、**休息**の終了は利用者の選択によってのみ起きる。
- **待機 (Wait)** — AI の出力待ちなどで主作業を離れ、短い別作業をしている状態。入った時点の**現在地**を**戻り先**として覚える。待機中に**現在地**を別の**ステップ**へ移しても**戻り先**は変わらない。**休息**ではない — **現在地**は**活性**のままであり、**連続作業時間**は数え続ける。**待機の長さ**が経つと**待機の介入**で主作業へ戻るきっかけを出すが、時間で自動終了はしない。戻り先・期限・何を待っているかは永続化しない。
- **戻り先 (Return Point)** — **待機**に入った時点の**現在地**。**待機**から戻るとき、**現在地**が別の**タスク**にあればここへ戻る (**切り替え**として**切り替え履歴**を 1 行残す)。同じ**タスク**の中にあれば (主作業を進めていた場合を含む) 動かさない。
- **待機の長さ (Wait Length)** — **待機**に入ってから**待機の介入**を発するまでの時間。「あと少し」が選ばれた後に出直すまでの時間でもある。待機に入るときに分で決め、その初期値は設定値 (既定 5 分)。**待機**を時間で終わらせる長さではない。
- **待機の介入 (Wait Intervention)** — **待機**が**待機の長さ**を超えたときに発する**介入**。「主作業に戻る」「あと少し」の二択を示す。契機は時間だけであり、AI の完了などの外部の出来事を見ない。残り時間・経過・回数を示さない。
- **腐敗 (Decay)** — 長期間**現在地**にならなかった**タスク**の状態変化。表示から外れていく過程を指す。データは削除されない。
- **観測 (Observation)** — **常駐プロセス**が最前面のアプリケーションおよびウィンドウの識別情報を継続的に取得する行為。取得対象はアプリケーション名とウィンドウタイトルであり、文書の内容および URL の全体は含まない。
- **作業文脈 (Work Context)** — **観測**により得られた、最前面のアプリケーション名とウィンドウタイトルの組。
- **固着 (Fixation)** — **本日計画**の要求に関わらず、**現在地**が更新されないまま単一の**作業文脈**が閾値を超えて継続している状態。
- **連続作業時間 (Continuous Work Time)** — 直近に**現在地**が非活性から活性へ遷移した時点からの経過時間。**切り替え**ではリセットされない。**休息**中およびシステムのスリープ中は計数されない。
- **猶予 (Grace Period)** — **介入**に対して「現在の**ステップ**を完了させてから移行する」が選ばれたときに与えられる延長時間。
- **再入 (Reentry)** — 中断された**ステップ**が再び**現在地**となり、作業が再開されること。状態ではなく出来事である。
- **開示面 (Disclosure Surface)** — 明示的な操作によってのみ到達する、**タスク**と**ステップ**の一覧。末尾に**思いつき**の欄を別に持つ (0 件なら出ない)。オーバーレイを閉じた時点で破棄される。
- **切り替え履歴 (Switch Record)** — **切り替え**の発生時刻と**中断メモ**記入の有無の記録。成功指標の測定基盤であり、ユーザーには表示されない。
- **移行期待時刻 (Expected Transition Time)** — **本日計画**において、あるタスクから次のタスクへ移るべき時刻。
- **思いつき (Idea)** — 作業中に浮かんだ別の作業を、**現在地**を動かさずに一行で置いたもの。**タスク**ではなく、**ステップ**を持たず、既定表示に出ない。**開示面**の末尾にのみ並び、そこから**タスク**へ昇格できる。昇格すれば消え、昇格しなければ**思いつきの寿命**を過ぎて消える。システムが削除してよい唯一のデータである。
- **思いつきの寿命 (Idea Lifetime)** — **思いつき**が置かれてから削除されるまでの時間。既定 14 日。消えたことも件数も知らせない。
- **作業区間 (Work Segment)** — **現在地**が**活性**だった時間の一区切り。**ステップ**の区間と、**待機**中に**現在地**が**戻り先**と同じ**タスク**にある間の待機の区間 (戻り先の**タスク**と何を待っているかを持つ) の二種がある。**休息**中・システムのスリープ中・**未着手**・**常駐プロセス**が止まっていた間は数えない。状態が変わった瞬間にだけ閉じた区間を記録し、開いている区間は永続化しない。勤怠・工数の報告のための参考値であり、**記録するが表示しない** — 読み手は書き出しのスクリプトだけである。

## 識別子対応表

コード上の識別子は英語とし、下表の対応を唯一の正とする。

| 用語 | 識別子 |
| --- | --- |
| タスク | `Task` |
| ステップ | `Step` |
| 完了 | `Completion` / `completed_at` |
| 現在地 | `CurrentPosition` |
| 活性 / 非活性 | `Active` / `Inactive` |
| 未着手 | `NotStarted` |
| 次の一手 | `NextAction` |
| 中断メモ | `InterruptionNote` |
| 本日計画 | `DayPlan` |
| 移行期待時刻 | `ExpectedTransitionTime` |
| ずれ | `Drift` |
| 交差 | `Crossing` |
| 切り替え | `Switch` |
| 切り替え履歴 | `SwitchRecord` |
| オーバーレイ | `Overlay` |
| 開示面 | `DisclosureSurface` |
| 常駐プロセス | `ResidentProcess` |
| 介入 | `Intervention` |
| 介入の選択肢 | `InterventionChoice` |
| 休息 | `Rest` |
| 休息閾値 | `RestThreshold` |
| 休息の長さ | `RestLength` |
| 介入の種類 | `InterventionKind` |
| 復帰の介入 | `InterventionKind::Return` |
| 待機 | `Wait` |
| 戻り先 | `return_to` |
| 待機の長さ | `wait_length_seconds` (`RestSettings::wait_length_seconds`) |
| 待機の介入 | `InterventionKind::Wait` |
| 腐敗 | `Decay` |
| 観測 | `Observation` |
| 作業文脈 | `WorkContext` |
| 固着 | `Fixation` |
| 連続作業時間 | `ContinuousWorkTime` |
| 猶予 | `GracePeriod` |
| 再入 | `Reentry` |
| 設定値 | `Setting` |
| 揮発ビュー状態 | `ViewState` |
| 思いつき | `Idea` |
| 思いつきの寿命 | `IdeaLifetime` / `idea_lifetime_seconds` |
| 作業区間 | `WorkSegment` / `work_segment` (開いている区間は `OpenWorkSegment`、種類は `WorkSegmentKind`) |

`NextAction`・`Drift`・`Fixation`・`Reentry` は v1 では型を持たない。`NextAction` は「現在地が指すステップ」の表示上の呼称であって別の型ではなく、`Reentry` は状態ではなく出来事である — これらを独立したエンティティとして実装してはならない。

## 申し送り

- **待機**中の時間は**主作業の時間に数えない**。待機中は主作業から離れて別作業をしているためである。→ **作業区間**として実装済み (2026-11-11): 待機中に**現在地**が**戻り先**と同じ**タスク**にある時間は待機の区間、別の**タスク**へ移った時間はそのステップの区間になる。
